## 2. Brand Design Tokens

| Property | Token Value | Purpose |
| :--- | :--- | :--- |
| **Primary Accent** | `#0f172a` (Slate 900) / `#3b82f6` (Blue 500) | Brand primary identity & buttons |
| **Display Font** | `Instrument Serif`, `Georgia`, serif | Editorial headings and hero title |
| **UI Body Font** | `Plus Jakarta Sans`, system-ui, sans-serif | Application menus, tool labels, dialogs |
| **Monospace Font** | `JetBrains Mono`, monospace | Metrics, checksums, hex inspection |
